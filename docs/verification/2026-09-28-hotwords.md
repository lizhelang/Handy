# 热词独立入口与输入优先级

用户要求把高级页的自定义词汇移到侧栏独立“热词”，位置靠前，并让打字和语音输入参考同一份词表。

热词入口位于通用之后，复用原 custom_words 数据和保存命令。高级页删除重复入口；输入法组合文字期间 Enter 不会误添加未完成的词。页面说明打字匹配到热词时优先展示、语音识别优先参考，实际结果由词库、上下文、发音及模型共同决定。

前端构建、受影响 ESLint、23 语言键一致性及相关页面回归通过。后端定点回归通过：个性化显式热词优先于学习词且撤下恢复、协议 2 项、共享排序 3 项、Whisper/Qwen 显式词提示优先 1 项。真实静态 Rime 用 zhongguo 的“中古”（原候选 rank 10）验证个性化与共享两条排序均升首位，保留原候选 id=rime:double_pinyin:10:2:0 并成功完整提交。共享回归包含单字热词及消费长度隔离。独立只读审阅无新增阻断。本机两组件已更新为 1.0.3 / 77，配对、运行签名和输入源恢复检查通过，tccChanged=false。实际侧栏“热词”为第二项；临时 Inputia热词验收 添加后磁盘保存成功，删除后词表恢复原来的 0 项。安装后资源再跑真实 Rime 后页热词用例通过（5.46 秒），原 rank 10 / native ID 保留并提交成功。

当前实现提升 Rime 原生候选池中的匹配热词，包括靠后的候选，保留原候选地址和正常选词学习。词库完全没有收录的新专名不通过伪造原生候选注入；任意新专名的拼音注册是另一项词典能力，本轮没有承诺实现。
