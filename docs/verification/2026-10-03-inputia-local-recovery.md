# Inputia 本机恢复与剪贴板生命周期验收

日期：2026-10-03。范围为本机受控版本，不代表公共发布验收。

## 修正与边界

- 正确源码分支为 `codex/unified-input-system`，不是旧的 0.9.0 分支；旧工作区与无关未提交修改保留。
- 剪贴板开关关闭时停止监听、作废旧读取并等待已进入提交区的工作完成；重新开启只建立当前剪贴板变更计数基线，不读取或补录已有内容。
- 历史输出账本在恢复时将未完成的 prepared 操作转为 rejected，防止自动重放。过去逐条无限时长启动警告使旧拒绝看起来持续发生；现在启动时只显示一次限时汇总，新事件仍正常提示，历史与账本不删除、不自动重试。
- 品牌清理复用既有连珠素材。应用图标来自 `macos/InputiaInputMethod/Resources/InputiaAppIcon.svg` / `Inputia.icns`，界面与托盘来自同目录 `InputiaLogo.svg`。本次误加的青底粉色同心圆已撤回，不作为新品牌。
- 输入法继续保留原有连珠数量选项。签名身份、组件 ID、数据目录与兼容协议标识不因视觉品牌清理而改名。
- 更新源保持独立；未配置 Inputia 更新源时不回退到上游更新。开源许可归属保留。
