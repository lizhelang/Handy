# 共享候选接入前移除输入法内容日志

真实接入阻塞：main.swift 的 INPUTIA_DEBUG_EVENTS 路径会记录按键字符/普通keyCode、组合串、提交正文、候选词、剪贴板正文、英文前缀/单词和窗口标题。共享词若进入该候选层，同样会被旧调试日志记录；即便仅显式启用调试，也不符合本项目内容日志合同。

本批只修改这些日志参数，保留状态、数量、候选序号、修饰键诊断；不改变插入、学习、排序、选词和隐私判断。普通keyDown不再记录可还原字符的keyCode；flagsChanged仅保留修饰键诊断。上下文日志不再保存窗口标题；历史日志未删除。

完整Host配对typecheck通过，日志 `/tmp/inputia-ime-log-privacy-typecheck.log`：现有Swift源码、生成配对公钥源与UnifiedPairAuth一起，以arm64-apple-macos13.0编译检查。diff检查通过。当前IME安装仍59，本源码修复尚未安装或进行原生调试日志测试。

此项仅解除共享候选接入的日志泄漏风险；认证取词、内存短缓存及候选排序/补全消费仍需实现，不称完整P4通过。
