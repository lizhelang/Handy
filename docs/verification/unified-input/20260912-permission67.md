# Inputia 测试版67：权限撤销/恢复与安全升级

承接 Codex 线程方案：把“系统有权限”和“输入控制已就绪”分开；撤权/暂停后不吞键、不积压；升级保留固定签名身份，不把删除权限项当成固定步骤。

## 实现

- 控制中心新增 `input_permission` 生命周期：被动探测辅助功能与输入监控，后台单 worker，超时只关准入并标 `restart_required`，不在主线程销毁监听器。
- 快捷键/Enigo/剪贴板/粘贴/语音派发等动作均按 epoch 准入；撤权或维护时 `close_gate`，恢复后重建并验证成功才显示就绪。
- 回调侧 `handy-keys` 在权限失效时直接放行；旧监听线程未退出前拒绝创建第二套；注册/注销/健康检查使用限时回执。
- 输入法侧 `InputiaPermissionLifecycle`：单飞 AX 查询、超时变 unknown、晚到结果丢弃、维护 ACK、退出立即关闸。
- UI：`InputiaPermissionHelp` 分别显示两个组件状态，提供“暂停后打开权限设置”与“重新检测并恢复”。
- 升级：`update-candidate.py` 固定证书身份、维护屏障（≥67）、事务备份回滚、不读写 TCC。
