## 修改

- 剪贴板监控在主线程先读changeCount；未变不再解码/编码相同图片。主线程只取现有API所需的快照，PNG编码/哈希/文件与DB写入在后台。监控许可覆盖排队、读取、后台处理；2秒超时不释放仍排队任务的许可，过期未执行任务跳过，避免积压。主动复制/写板API语义不变。
- 录音stop最多3秒，尾部排空使用绝对2秒截止（不会因连续数据重置）；初始化握手5秒，close等待最多100毫秒且仅join已退出线程。超时置故障/停止供数，shutdown只发一次，保留worker句柄并阻止重复open到其退出。VAD切换失败保留隔离worker并恢复其未来使用的旧配置，避免运行backend与未提交设置不一致。
- 窗口枚举在后台单任务执行，主线程最多等待25毫秒；超时结果不复用、不堆积。语音AX读取具有100毫秒累计预算，每次最多50毫秒；不再回退到无外层时限的IMK选区读取。无法核实选区时保留历史，不自动投递；真正派发仍校验原客户端、焦点、选区、敏感字段、组合与派发截止。
- 查询失败保持明确可用性状态，普通输入走不学习的直通路径，拒绝剪贴板读取/学习；不把失败当无标题成功。成功但确无标题仍保留原行为。
