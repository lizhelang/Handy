# Inputia 离线中文续词试验（2026-10-14）

**结论：这份模型在本机足够快，但本次固定协议的质量未达到默认启用门槛。** Raw context 的有用续词为14/20，低于事先要求的16/20；assistant-prefill为9/20。未因这些结果改提示或换模型。

试验只使用任务自写公开合成上下文。未读取用户输入、模型设置或聊天资料，未更改产品源码。模型和runtime只在本目录；试验服务仅绑定127.0.0.1，已退出且端口关闭。

|方案|有用/20|非空覆盖|完整候选p50|完整候选p95|8条上下文挑战|
|---|---:|---:|---:|---:|---:|
|Raw context|14/20|17/20|24.68 ms|45.23 ms|4/8|
|Assistant prefill|9/20|14/20|45.68 ms|84.14 ms|2/8|

表中延迟只统计人工判为自然、可直接拼接的完整候选；没有把第一个token或单个汉字当作可用短语。Raw所有20次完成p95为48.96ms，prefill为100.15ms。格式受grammar约束，20/20格式有效不能作为语义质量证据。空候选独立计为弃权/未覆盖，不强行判成错误答案，也不计入有用续词。

新进程、`--no-warmup`：启动至ready 1.083秒，至首个完整自然候选“发个消息”1.123秒；首条请求本身39.0ms。只测一次进程冷启动，OS文件缓存未清，不是磁盘冷启动。进程RSS约2.24GiB。相同短上下文常驻重复5次，中位数32.34ms，开启prompt cache后28.90ms。

公开重复段落的64/256/512字长度测试，各3次完整候选中位数为44.99/71.86/120.50ms。该组仅测长度成本，不作为长上下文智能合格的证据。另两条真实主题长段落中，raw均未给有用续词，prefill仅1条有用。
