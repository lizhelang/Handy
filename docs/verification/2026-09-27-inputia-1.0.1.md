# Inputia 1.0.1 修复验收

## 用户要求

保留自然码双拼并增加全拼兼容；修复历史记录页面被侧栏遮挡和横向溢出的问题。

## 页面修复

主内容补齐收缩约束，历史页使用可用宽度。标题工具栏可换行，列表与预览在窄窗口纵向排列，长来源与正文可断行。

真实 App 与历史页使用模拟原生接口回归：600、720、1000 像素窗口及 15、20、30 像素字体，共 5 项通过。原历史行为 18 项通过。修复前长来源导致历史页左边界为 -1177 像素；修复后位于侧栏右侧且无横向溢出。前端构建与受影响 ESLint 通过。

## 输入兼容与安装

自然码保留原双拼编码并派生全拼音节，仍用 Rime 原生候选、选择与学习。真实静态引擎验证 edu → 额度、vsgo / zhongguo → 中国、nihaoma → 你好吗；全拼、双拼和混合输入部分选择“中”后，剩余编码可继续选择“国”。非首位候选选择三次后重开引擎升到首位。资源单测 11 项、真实 schema 回归 8 项通过；限定自然码修正后综合用例再次通过。

版本为 1.0.1，构建号 75。两组件配对更新成功，运行签名身份校验通过，原输入源已恢复，tccChanged=false。实际控制中心和输入法均为 1.0.1 / 75；设置仍为 double_pinyin。安装后的 RimeData 再次运行综合真实引擎用例通过（5.36 秒）。实际控制中心历史页已确认标题、工具栏完整，无侧栏遮挡和横向滚动条；当前大字号下列表和预览纵向排列。备份位于 ~/Library/Application Support/HandyUnifiedBuilds/permission-update-pdb_xc2n。浏览器页面回归和引擎回归不替代原生物理键盘验收。

## 更新后 IMK 连接故障与恢复

用户随后报告无法打字。空白 TextEdit 窗口复现：字母按键没有文本和候选。IME 进程仍在，主线程空闲；维护为 false、权限 ready，当前 TIS 为 Inputia.Hans。imklaunchagent 日志明确报 `Refusing connection name for bundle: unrecognized 'InputMethodConnectionName' value`。因此仅验证版本、签名、TIS 选中和离线引擎不足以确认实际输入。

切到 ABC、退出旧 IME 服务、使用 lsregister -f 刷新已安装 app 注册并重开、重新选择 Inputia 后，实际 TextEdit 按键 `vsgo` + 空格提交“中国”，`edu` + 空格提交“额度”，已由 AX 文本确认。没有修改连接名、用户字库、数据或授权。

更新器新增两组件注册刷新，完成注册后才启动和恢复输入源；注册失败进入现有事务回滚。更新器 7 项回归通过，包括注册先于启动以及注册失败不得启动。
