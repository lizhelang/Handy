# Inputia 快捷键被安全输入阻止

macOS 的安全输入用于保护密码等敏感输入。它开启时，Inputia 可能无法接收全局快捷键；这不表示历史内容丢失。

1. 离开密码输入框，结束正在进行的登录或授权操作。
2. 如果提示指出某个应用，先完成该应用的敏感输入；必要时正常退出并重新打开该应用。
3. 如果终端中自行开启了“安全键盘输入”，只在不需要保护敏感输入时自行关闭。不要为了快捷键关闭仍在使用的密码保护。
4. 状态恢复后重新按快捷键；旧录音和待处理输出不会自动重放。

这与麦克风或辅助功能授权是不同问题。不要删除系统授权记录，也不要因这条提示反复重授权限。仍无法恢复时，在 Inputia 的历史记录中查看已保存内容，并提供状态提示给项目维护者。
