# 剪贴板跨桌面与外部点击关闭

## 实现边界

- 保留 `CanJoinAllSpaces`，不叠加与其互斥的 `MoveToActiveSpace`。
- macOS 不再用窗口失焦关闭浮窗：切换桌面、切换应用不等价于点击外部。
- 使用 AppKit 全局和本地鼠标按下监听器；全局处理其他应用，本地按窗口编号区分浮窗内外。
- 置顶时忽略外部点击；Escape 沿用前端关闭流程。
- 监听器仅注册一次，窗口销毁及应用退出时移除；不监听键盘，不增加麦克风或辅助功能授权要求。
- 显式声明已经锁定的 `block2 0.6`，用户已授权。激活应用使用兼容旧系统的 API。

## 验证注意

- 本机 Spaces 快捷键为 Option 加左右方向键，不是 Control 加方向键。只有观察到实际 Spaces 变化才算切换验证。
- 多显示器截图和单窗口截图不能独立证明实际桌面已切换。
- 本地安装必须使用 Tauri CLI 生成的完整应用包；不要用普通 Cargo 二进制替换应用包。
- 本地构建可临时关闭 updater artifacts；不修改正式更新签名配置。
- 无语音权限时使用托盘的“剪贴板历史”入口，不要依赖权限引导之后才初始化的快捷键。
