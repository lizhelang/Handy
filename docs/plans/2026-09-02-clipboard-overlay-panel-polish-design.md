# 剪贴板浮窗面板化与 Ropy 精华重接设计

## 参考基线

- Ropy：`StudentWeis/ropy@1264415bf7d8746d5333f7a0405fecd15f466084`（2026-08-05），MIT。
- Ropy 当前采用 Rust + GPUI；Handy 保持 Tauri + React，不移植 GPUI。
- 本次只借鉴产品行为、内容模型和视觉节奏，保留 Handy 的粉色品牌、收藏命名和既有 SQLite 数据。

## 根因

1. macOS `clipboard_overlay` 使用普通 `WebviewWindow` 且 `decorations(true)`，原生标题栏与 React 自绘顶部栏叠加，所以顶部多出一截。
2. 网页层只有 `12px` 圆角，但外层仍是矩形原生窗口；内容圆角不能替代真正的窗体裁切与阴影。
3. 普通窗口没有声明 Spaces/全屏辅助行为，切换桌面后会留在创建它的 Space。
4. Handy 数据模型已经预留 `file` 类型和文件筛选 UI，但监听器只真正采集文本/图片，导致文件筛选长期为空。

## 方案比较

### A. 只改 CSS

速度最快，但无法去掉原生标题栏，也无法解决 Spaces 行为；不采用。

### B. Tauri 原生面板 + 交互补齐（采用）

将 macOS 浮窗改为 `tauri-nspanel`，前端做精确视觉收敛；同时补齐文件剪贴板和 Ropy 中适合高频调用的键盘操作。改动集中、无需更换技术栈，也不修改现有数据库结构。

### C. 完整复制 Ropy

包含 GPUI、redb、HTML/RTF sidecar、更新器和整套设置。会破坏 Handy 的上游结构与现有数据边界；不采用。

## 详细设计

### 1. macOS 窗口壳层

- 新建可获得键盘焦点的 `ClipboardOverlayPanel`。
- 无系统标题栏、无红黄绿按钮、透明背景、原生阴影，面板与网页根容器统一为 `22pt/px` 圆角。
- 固定内容尺寸 `400 × 550`，删除标题栏后外部尺寸与 Ropy 同量级，不再额外放大窗口。
- Collection Behavior 使用：
  - `CanJoinAllSpaces`：可见时跟随所有桌面；
  - `FullScreenAuxiliary`：可在全屏应用所在 Space 显示；
  - `Transient`：在 Mission Control 中表现为临时工具面板；
  - `IgnoresCycle`：不进入普通窗口循环。
- 不长期叠加 `MoveToActiveSpace`；`CanJoinAllSpaces` 已满足左右滑桌面跟随，并减少激活/排序异常风险。
- 每次显示仍按鼠标所在显示器重新居中，保留多屏行为。

### 2. 视觉规格

- 外层圆角：`22px`；原生面板负责裁切与阴影，网页不再制造第二层“假窗口”。
- 内容内边距：顶部/左右 `18px`，底部 `16px`。
- 顶部操作按钮：`40 × 40px`；搜索和筛选胶囊高度 `42px`。
- 列表卡片圆角 `12px`、间距 `10px`，选中态为 Handy 浅粉底 + 单像素品牌描边。
- 图片缩略图圆角 `10px`；索引徽标高 `22px`、圆角 `7px`。
- 保留系统字体栈和 Handy 品牌粉，不复制 Ropy 蓝色。
- 空态减少大块硬边白框，使用轻描边、柔和底色和明确说明。

### 3. 文件剪贴板

- 检测优先级调整为 `Files > Image > Text`，避免 Finder 文件被降级为路径文本。
- 规范化 `file://`、`file://localhost`、百分号编码和多文件列表。
- 利用现有 `content_type = file` 与 `full_text` 字段，以 JSON 数组保存路径；不新增数据库迁移。
- 列表显示首个文件名、路径和多文件数量；搜索继续匹配完整路径。
- 确认文件记录时调用系统文件剪贴板 API 原样回写，而不是复制一段路径字符串。

### 4. 高频交互

- `/`：聚焦并全选搜索框。
- `↑/↓`、`J/K`：移动选择。
- `1–5`：直接确认当前可见前五项。
- `Enter`：按原格式确认；`Shift+Enter`：以纯文本确认（文件为换行路径）。
- `F`：收藏；`P`：记录置顶；`D/Delete`：删除。
- 按住 `Space`：预览当前项，松开关闭；复用现有图片/文本/文件预览能力，不增加新的持久设置。
- 更新浮窗帮助面板，使快捷键可发现。

### 5. 数据与边界

- 不改现有表结构，不重写历史数据，不触碰收藏、命名、Inputia、模型或 FunASR/Sherpa/热词工作。
- 自动清理仍只删除未收藏且未置顶的普通记录。
- 暂不引入 HTML/RTF sidecar：无损富文本需要独立存储与迁移，另做可回滚版本更稳妥。
- 不复制 Ropy 的更新器、redb、托盘生命周期和 GPUI 窗口代码。

## 验收标准

- macOS 浮窗无系统标题栏和交通灯，顶部只剩一层 Handy 自绘栏。
- 外轮廓圆角、阴影与网页内容连续，无方壳或双重圆角。
- 在同一显示器左右切换 Spaces，浮窗仍可见；全屏 Space 可显示。
- Finder 复制单个/多个文件后，文件筛选中出现记录，确认后仍能作为文件粘贴。
- `/`、1–5、P、Space、Shift+Enter 等快捷操作有效且不会在搜索输入时误触。
- 全量 Rust/前端/i18n/格式门禁通过；真实 App 做窗口、Spaces、文件回写和数据计数验收。
