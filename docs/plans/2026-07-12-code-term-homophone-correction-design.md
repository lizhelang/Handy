# 代码术语中文近音纠错设计

## 目标

为词表中形如 `main分支` 的“ASCII 代码词 + 中文后缀”增加安全的中文近音纠错；它不能把 Qwen ASR 的 context 变成强制词典，也不能改写普通中文。

## 边界

- 仅从包含 ASCII 前缀和连续中文后缀的自定义词中生成候选，例如 `main分支`。
- 仅从转写中抽取紧贴同一中文后缀的短中文片段，例如 `命分支`；普通中文词表项不会进入此路径。
- 专用本地 Qwen 复用现有 JSON 纠错格式，但候选词表仅含匹配到的代码术语；它仅可把预先声明的 `source` 或一字中文上下文版本替换成配对的 `target`。若引用了上下文，程序保留该字，回复中的任一其他来源、目标或文本改写均拒绝。
- Qwen 不确定时必须返回空替换；之后仍运行现有通用词表纠错。

## 实现计划

1. 在 `src-tauri/src/custom_words_model.rs` 为代码术语候选添加纯函数及测试：覆盖 `命分支 → main分支`、普通中文词条排除、已有 `main分支` 排除、无关后缀排除。
2. 为专用 prompt 和严格响应验证添加测试：只允许候选中的 source/target 配对，拒绝同词表但未声明的替换。
3. 让本地纠错流程优先调用专用代码术语 prompt；无候选或模型弃权时保留既有通用纠错流程。
4. 执行单元测试、全量 Rust 测试、前端检查和 release 构建；替换 `/Applications/Handy.app`，使用保留的录音复测。
