## Plan

# 目标

在不迁移或丢失任何既有数据的前提下，把 Handy 剪贴板浮窗改造成无标题栏、统一圆角、跨 macOS Spaces/全屏可见的原生面板，并补齐 Ropy 中适合 Handy 的文件剪贴板与高频键盘交互。

# 执行步骤

1. 记录当前数据库计数、应用签名与回滚包；为窗口配置、文件路径规范化和内容优先级建立回归测试。
2. 将 macOS `clipboard_overlay` 切换为可获得焦点的 `tauri-nspanel`：borderless、透明、原生阴影、22pt 圆角、CanJoinAllSpaces、FullScreenAuxiliary、Transient、IgnoresCycle。
3. 收敛 React/CSS 视觉：移除双层窗口感，统一外圆角、控件高度、卡片圆角和 Handy 品牌选中态；补齐文件卡片表达。
4. 实现文件剪贴板：Files 优先检测、URI/百分号编码规范化、JSON 路径存储、单/多文件原样回写；不新增数据库列。
5. 增加 `/` 搜索、1–5 快选、P 置顶、D/Delete 删除、Space 按住预览、Shift+Enter 纯文本确认，并更新帮助文案和全部语言键值。
6. 运行 Rust、TypeScript、ESLint、翻译、格式与 Playwright 门禁；用隔离数据做文件捕获/回写测试和视觉截图对比。
7. 独立代码审查后构建签名 App，保留当前安装包回滚副本，替换 `/Applications/Handy.app`；实际验证标题栏、圆角、Spaces 跟随、文件筛选/回写及数据库计数。
